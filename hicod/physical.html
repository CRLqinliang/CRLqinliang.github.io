V0.4 / ARTICULATED PHYSICAL EVIDENCE

Debug the solution space.

Explore an articulated 3R robot carrying a circular object along a prescribed path. Eight ideal attachment directions, two IK branches and sampled transition checks expose the difference between local feasibility and a continuous-mode candidate family.

Live analytic geometry, not a MuJoCo runtime. The browser computes FK, IK, pairwise signed clearances, joint limits and sampled graph structure. The MuJoCo 4 replay adapter is available but has not been runtime-tested. No real grasp, continuous edge certificate or dynamics is claimed.

REPRODUCIBILITY

Same geometry, two backends

Export the candidate probes, replay them in MuJoCo 4, reconstruct the graph from the new distance evidence, and compare the result. The analytic backend and replay share the same sample IDs, IK and path scope.

cd hicod
node examples/planar3r.mjs disconnected --raw raw.json --report report.json
pip install -r requirements.txt
python examples/mujoco4_articulated.py raw.json mujoco_replay.json
node examples/planar3r.mjs disconnected --replay mujoco_replay.json --report replay_report.json
node tests/test_planar3r.mjs

The MuJoCo commands are provided for local reproduction; the authoring environment could not install MuJoCo. The designed analytic scenes are not an unbiased success-rate benchmark.
