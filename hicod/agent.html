V0.6 / AGENT-FACING DIAGNOSTICS

Query. Drill down.

Start with the structure of a solution space. Query relevant concepts, trace evidence and compare permitted interventions on demand. Six tools share one task session.

This is an executable deterministic tool playground, not a live LLM experiment. All claims are scoped to the analytic planar 3R model and finite evidence. No robot commands are issued.
